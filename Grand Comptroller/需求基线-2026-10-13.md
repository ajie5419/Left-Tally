# Grand Comptroller 需求基线

版本：1.0。整理日期：2026-10-13。

本文件依据当前会话中第 1–72 题、第 12 题补充及用户的最新更正整理。它记录已经确认的产品规则，不代表软件已开发、接口已具备或业务验收已通过。第 72 题最终口径为“暂时没有真实样例，先设计，样例核实保留为待办”，替代此前“有电子文件”的回答。

业务现状见 [履约业务流程草案](履约业务流程草案-2026-10-12.md)；工程设计见 [关键业务设计](关键业务设计-2026-10-13.md)。发生歧义时，以用户最新明确决定为准。下表中的 Q 编号对应本次会话题号，用于追溯，不是已执行测试编号。

## 1. 首版范围与外部边界

以项目为主线、设备为工单，每台设备独立计划。一个项目对应一份合同，同型号多台设备分别建工单。支持分批设计、采购、制造、交接、发运和客户验收。

| 范围 | 本轮基线 |
| --- | --- |
| 履约系统 | 计划、制造安排与进度、交接、齐套、资料下发记录、变更影响、问题与措施、发运批次、验收关联及履约汇总 |
| QMS | 质量检验、质量处置、质量放行；供应商与外协单位、部门、人员、班组档案；账号统一管理方向 |
| K3 | 正式采购申请、采购订单、收料、财务、库存和领料；物料业务编码仍以 K3 为准，首版不接 K3 |
| 数据展示 | 不展示合同金额、采购单价、具体付款金额；可以显示影响履约的付款、提货等状态 |
| 使用端 | 电脑端为主；手机浏览器支持查询、进度更新、交接等少量操作 |
| 首版新增计算 | 自动判断并行阶段、按依赖预测首批发货、自动计算理论可做套数 |
| 保留线下方式 | 图纸及工艺资料继续纸质或现有渠道交付；现场继续通过微信群沟通 |

自动预测属于首版目标，不能扩展为自动排产。QMS 同一账号方向已确定，认证协议、会话互通和接口能力未验证；不能宣称已有单点登录。图纸不强制上传，不取消客户验收文件关联和交接单可选附件。

## 3. 职责及权限落点

| 角色 | 常规维护范围 | 特别边界 |
| --- | --- | --- |
| 事业部销售 | 客户承诺及确认依据、客户变更、进场条件、签字验收关联 | 不能用内部预测覆盖客户承诺；逐设备录入验收结果 |
| 项目部 | 工单计划、任务依赖、最终计划协调、供料分配、首批初次确认、项目关闭、措施延期确认 | 可以代录、更正、调整首批；不能代替 QMS 质量判定 |
| 统一派工负责人 | 部件工序任务确认、安排、未开工范围转派 | 保存即安排，不能自动记为开工或收到 |
| 生产项目负责人 | 负责工单的制造进度、交接与差异、实际齐套、总装、发运编排、现场汇总及恢复确认 | 不关闭其他部门问题，不修改质量判定 |
| 生产负责人 | 生产统筹和已授权的代录、更正 | 与生产项目负责人角色区分；实际岗位兼任以授权映射 |
| 技术 | 专业任务和调试进度、装配配套、资料版本及变更处理要求 | 不能从 BOM 猜测未确认的装配层级 |
| 工艺、采购及其他部门 | 自身任务进度、计划反馈、对应资料／到货记录 | 跨部门可查看，不获得全域修改权 |
| 责任部门负责人 | 处理人员安排、处理结论及问题关闭、岗位移交 | 关闭问题不自动恢复现场或追回工期 |
| 品质 | QMS 检验、放行、质量问题处置及现场质量关闭 | 不在履约系统建第二套判定台账 |
| 分管领导 | 对应部门的逾期升级接收 | 接收提醒不自动取得其他记录的编辑权 |

授权的代录或更正属于操作责任，不改变原业务责任人；技术要求确认、QMS 放行及项目关闭等专门责任不能被通用代录权限自动替代。

## 4. 已确认规则之间的组合口径

1. **首次范围确认与后续调整不同**：首批初次由项目部确认（Q36）；之后生产项目负责人、项目部可修改并立即重算（Q37、Q38）。不新增逐次审批。
2. **工单完成与项目关闭不同**：销售登记客户验收通过即可工单完成（Q63、Q64）；项目部核对后关闭项目，遗留可按承接条件继续跟踪（Q14、Q65）。
3. **预测目标与合同节点不同**：首版只自动算首批发货（Q33、Q34）；合同风险仍按实际节点判断（Q35），不能把未建预测能力的节点当作按时。
4. **计算工期与信息时效不同**：预测和剩余天数按自然日（Q11、Q29）；在制确认提醒按工作日（Q10）。公司工作日历和提醒切点仍需落实。
5. **质量门禁与事实留存不同**：无放行不得正式登记下道开工；违规实际发生时间、范围和原因进入异常证据，不用放行后的时间伪造现场历史（Q12 及补充）。
6. **问题关闭与暂停解除不同**：部门负责人关闭问题（Q08）；技术变更暂停解除还需技术落实结论及现场恢复确认（Q55），不增加普通问题关闭审批。
7. **一般数量选填与受控范围不同**：不要求每天填开工数量；转派、部分放行及分批下道开工必须能识别本次允许范围，不能以“未知”为由放开全量。
8. **信息共享与金额共享不同**：各部门看全部工单进度（Q56）；首版金额字段不进入展示或返回数据（Q57）。

| E09 | 报废补制、计量换算、历史验收撤销／纠错的实际制度 | 品质、技术、项目部、销售 | 不以普通更正新增产量、不静默撤销验收；实施相关用例前专项核对 |

待办不是新增业务审批；其中角色建议用于证据收集，不是已任命的个人负责人。缺样例只阻塞实际格式适配和相关验收，不阻塞独立设计。
