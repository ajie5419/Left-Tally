## 4. 模块及依赖

最低工程组织为 `apps/web`、`apps/api`、`packages/contracts`。后端按实际业务建立 domain、application、infrastructure；不创建大量空业务模块。

| 来源 | 允许依赖 | 禁止依赖或行为 |
| --- | --- | --- |
| web | 自身界面、公开 contracts、前端 API 客户端 | 后端内部实现、Prisma/数据库驱动、正式代码引用测试 fixture |
| routes | contracts、应用用例、HTTP 基础设施 | 直接读写数据库、直接请求 QMS、权威业务计算 |
| domain | 本模块纯规则、稳定类型、必要精确数值工具 | HTTP/数据库/框架请求对象、环境读取、隐式当前时间 |
| application | domain、端口接口、公开契约 | 绕过授权/事务及适配直接访问外部系统 |
| infrastructure/适配 | 相应端口、数据库或外部客户端 | 用通用数据访问承担业务准入决策 |
| contracts | 类型、Zod、稳定公开编码 | Vue、数据库实体、后端实现及权威业务算法 |

组合入口负责依赖注入，不让领域层直接依赖基础设施。跨模块使用公开应用接口，不引用其他模块内部数据访问。

使用标准检查工具解析依赖，推荐 ESLint 配合 dependency-cruiser。覆盖 TS/Vue、相对路径、tsconfig/workspace 别名、类型导入、重导出和可解析动态导入；无法解析或循环依赖失败。生产中的非字面量动态加载默认拒绝，框架必要入口按具体范围复核。

静态检查不能证明所有函数语义正确，禁止以函数改名、移动文件或拆 helper 作为职责已修复的证据。

## 5. 初始静态标准

| 项目 | 设置 |
| --- | --- |
| 类型 | TypeScript strict、noUncheckedIndexedAccess、exactOptionalPropertyTypes，前端 vue-tsc |
| 文件有效行 | 普通 TS 400，Vue 500；Vue 计入模板/脚本/样式 |
| 函数有效行 | 80 |
| 复杂度与嵌套 | 12 与 4 |
| 类型逃逸 | 生产代码拒绝 explicit any、ts-ignore/ts-nocheck 及危险断言；具体必要例外独立复核 |
| 异步与错误 | 检查浮置 Promise、误用 Promise、空 catch；失败不假报成功 |
| lint 忽略 | 生产源码内不得自行削弱规则；例外在受保护配置中明确 |
| 测试缩减 | 必需套件拒绝 only/skip/todo；计划场景不作为已运行测试 |
| 格式 | Prettier 检查，lint 零警告 |

有效行排除空行和纯注释。实现时验证 Vue 计数及规则支持，不以解析器漏扫当通过；若工具不能表达，增加最小专用检查并以边界样例证明。测试文件不机械使用生产体积阈值，但其类型、依赖及断言仍受约束。

阈值是本项目初始实施基准，不是通用标准。超限先检查职责，再进行最小拆分或提出具体例外。即使不超限，混合多个无关业务、巨型工具文件和跨请求可变全局状态仍须审查拒绝。

## 6. 硬编码与业务权威

| 内容 | 归属 |
| --- | --- |
| 人员/部门/班组/供应商/工单/图号 | 权威主数据及稳定 ID，不按固定名称写业务特例 |
| 可调整提醒和业务参数 | 有负责人、适用范围与变更历史的配置 |
| 固定状态/错误码/单位编码 | 所属模块命名常量；真正共享的进入契约 |
| 环境地址和运行参数 | 统一配置入口，公开前端配置与私密后端配置分开 |
| 示例人员/数量/质量结果 | 隔离测试 fixture，不作正式业务默认值 |

普通分页、颜色和索引等正常字面量允许保留。不把所有常量塞入一个巨型文件，不把不可绕过的质量红线改为随意开关。未知数量/身份/资格不以 0、true 或虚构记录兜底。

前端允许格式化、布局、当前页筛选、输入提示和展示后端结果/原因/缺项。可派量、同批可开工范围、质量放行、暂停解除、权限/工单归属、理论齐套、自动阶段、首批预测及合同风险由后端权威决定。

预览调用后端；正式提交重新校验事实、权限及版本，不信任客户端传入的已放行、角色或可用量。前端静态检查无法识别所有重写算法，必须结合规则归属审查及绕过 UI 的拒绝测试。

同一业务规则保留一个权威实现，各入口结果一致；不同业务语义不能仅因相似代码被盲目合并。共享契约公开 DTO，不直接暴露数据库实体。时间基准显式传入，精度、单位、自然日/工作日统一处理；事务、锁和幂等必须用实际竞争及失败回滚证明。
